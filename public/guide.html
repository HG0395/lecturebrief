첫 녹음부터 마지막 공지까지

LectureBrief는 녹음을 전사하고, 교수님이 사용 중인 Claude에서 강의를 정리한 뒤, 결과를 검토해 공지와 진도를 관리하는 도구입니다. AI API 키를 등록할 필요가 없습니다. 아래 순서는 실제 작업실의 버튼과 같습니다.

1. 강의 정보와 원문 준비

과목명, 강의 날짜, 주차를 입력합니다. 녹음 파일 또는 TXT·SRT·VTT 전사문을 선택할 수 있습니다. 전사문은 최대 240,000자이며, 오디오 파일은 100MB 이하입니다. 큰 녹음은 수업의 휴식 시간이나 주제 전환을 기준으로 나누는 편이 좋습니다. 음성 파일만 선택해서는 정리가 시작되지 않습니다.

녹음 전사하기를 누르면 Whisper 모델을 처음 내려받고 브라우저에서 한국어 음성을 처리합니다. Tiny는 속도, Base는 더 큰 모델을 원하는 경우의 선택지입니다. PC와 녹음 환경에 따라 정확도와 시간이 달라집니다. 녹음 언어는 한국어·영어·자동 감지 중 선택할 수 있습니다. 실제 언어와 다르게 설정하면 오인식할 수 있습니다. 반복되는 구절이 감지되면 확인 안내를 표시합니다. 이 안내는 모든 오인식을 찾아내는 기능은 아닙니다. 두 모델 모두 한국어를 지원하지만 전문용어와 숫자를 정확히 인식한다는 보장은 없습니다. 중단 버튼은 진행 중인 전사를 끝내며 기존 전사문은 유지합니다.

2. 전사 오류 먼저 고치기

전사문에서 교재 쪽수, 과제 개수, 제출 장소, 시험 범위를 먼저 확인하세요. “15일”과 “25일”처럼 숫자가 바뀌면 공지의 의미가 달라집니다. 원문 근거를 찾기 쉽도록 타임스탬프를 유지하세요. 강의계획서와 이전 진도는 선택 항목에 붙여넣을 수 있지만 실제 수업 진도를 대신하지 않습니다.

3. 교수님의 Claude에 전달하기

  1. 정리 요청문 복사를 누릅니다. 전사문과 수업 정보, 정리 규칙이 함께 복사됩니다.
  2. Claude 열기를 누르고 교수님 본인의 계정에 로그인합니다.
  3. 요청문을 붙여넣어 전송합니다. 이때 전사문이 Claude에 전달됩니다.
  4. Claude가 출력한 JSON 객체 전체를 복사해 돌아옵니다.
  5. Claude 정리 결과 입력란에 붙여넣고 결과 가져오기를 누릅니다.

과목별 Claude Project를 만들고 강의계획서와 반복해서 쓸 지침을 추가하면 편리합니다. 이전 대화를 무조건 기억한다고 가정하지 말고 필요한 이전 진도를 매번 함께 제공하세요. 요청이 너무 길다는 안내를 받으면 전사문을 차시별로 나누어 각각 정리합니다. 이 사이트가 Claude 로그인이나 구독을 대행하지는 않습니다.

4. 공지와 진도 검토

강의 전체 정리에는 전체 개요와 주제별 상세 정리가 표시됩니다. 내용은 모두 수정 가능합니다. 공지사항 탭에서는 제목·본문·마감일을 원문 근거와 대조한 뒤 “학생에게 공지해도 됩니다”를 체크하세요. 새로 가져온 공지는 항상 미검토 상태입니다. 공지 내용을 다시 수정하면 검토 완료 표시도 해제됩니다.

상대적인 기한을 확정하지 않는 예

원문: “다음 수업 전까지 PDF로 제출하세요.”
공지 초안: “다음 수업 전까지 PDF로 제출합니다. 정확한 제출일은 LMS에서 확인하세요.”
마감일: 비워 두고, 교수님이 실제 날짜를 확인한 뒤 입력합니다.

수업 진도는 완료 범위·다음 예정 범위·준비 사항을 구분합니다. 계획서상의 주차와 실제 강의가 다르면 원문을 우선해 수정하세요. 강의에서 언급되지 않은 다음 진도를 추측해서 채우지 마세요.

5. 공지 게시와 보관

공지문 복사는 검토 완료한 공지를 일반 텍스트로 복사합니다. LMS용 서식 복사는 제목과 문단이 있는 HTML 서식을 함께 복사합니다. LMS 편집기의 서식 지원에 따라 표시가 달라질 수 있습니다. 공유하기는 기기의 공유 메뉴를 열며, 지원하지 않는 브라우저에서는 텍스트 복사로 대신합니다. 실제 LMS 게시나 메시지 전송은 교수님이 직접 합니다.

일정 저장은 날짜가 확정되고 검토 완료한 공지를 종일 일정의 ICS 파일로 만듭니다. 마감 시각이나 알림은 설정하지 않으므로 캘린더에서 별도로 확인하세요. 정리 파일은 Markdown, 전사문과 공지는 TXT로 저장합니다. 이 기기에 저장은 현재 브라우저에 전사문·수업 정보·수정 결과를 보관하며 다른 기기에는 동기화하지 않습니다.

모바일과 키보드

휴대전화에서는 입력과 Claude 전달 영역이 위아래로 배치됩니다. 긴 녹음은 PC 사용이 편리합니다. Tab으로 입력과 버튼을 이동하고 Enter 또는 Space로 실행합니다. 결과 탭은 좌우 방향키로 이동하며 Home·End로 첫 탭과 마지막 탭을 선택할 수 있습니다. 새 강의와 예시 열기는 기존 작업이 있을 때 교체 여부를 확인합니다.

녹음에서 검토한 공지까지

녹음을 브라우저에서 전사하거나 텍스트 전사문을 가져온 뒤 Google Gemini가 강의 전체 정리·공지·진도를 생성합니다. 녹음 전사와 강의 내용 정리는 별도 단계입니다.

1. 자료 종류 선택

과목·날짜·주차를 입력하고 녹음 파일 또는 전사문 텍스트 파일을 선택합니다. 파일 선택과 끌어 놓기를 지원합니다. 녹음은 100MB 이하·2시간 이하, TXT·SRT·VTT는 2MB 이하·240,000자 이하입니다. 선택한 종류와 다른 파일은 안내하고 거절합니다. 종류를 바꿔도 전사문은 유지되며, 선택한 녹음 해제에는 확인이 필요합니다.

2. 녹음 전사와 원문 확인

녹음을 선택했다면 모델과 녹음 언어를 정하고 녹음 전사하기를 누릅니다. Tiny는 빠른 처리, Base는 더 큰 모델을 위한 선택입니다. 언어는 한국어·영어·자동 감지를 지원합니다. 첫 실행에는 모델을 내려받으며 브라우저와 코덱에 따라 실패하거나 오래 걸릴 수 있습니다. 중단은 기존 전사문을 유지합니다. 반복 구절 안내가 모든 오인식을 찾지는 않습니다.

텍스트 파일은 UTF-8로 준비하세요. 가져온 전사문에서 전문용어·숫자·교재 쪽수·기한을 먼저 고치고, 학생 이름·성적·연락처는 제거하세요. 타임스탬프는 근거 확인에 유용합니다. 강의계획서와 이전 진도는 선택 입력입니다.

3. Gemini로 강의 정리

운영자의 서버 설정이 완료되면 연결 준비 상태가 표시됩니다. Google 전송 동의를 체크한 뒤 강의 정리 시작을 누릅니다. 별도 이용 코드나 API 키 입력은 필요 없습니다. API 키는 운영자의 서버에만 설정합니다.

버튼을 누르면 전사문·과목·날짜·주차·강의계획서가 Cloudflare 서버를 거쳐 Google Gemini로 전달됩니다. 녹음 원본은 전송하지 않습니다. 운영자의 Google API 사용량과 요금·한도가 적용될 수 있습니다. 생성 중에는 중복 요청을 막으며 자동 재시도하지 않습니다. 정리 중 원문을 바꾸면 결과 JSON만 준비하고 자동 적용하지 않으니 확인 후 직접 가져오세요.

4. 결과와 공지 검토

전체 정리·공지·진도 탭의 내용을 수정할 수 있습니다. 원문에 없는 과제나 기한을 만들어내지 않았는지 확인하세요. 상대 기한은 실제 날짜를 확인하기 전까지 비워 두세요. 새 공지는 모두 미검토 상태이며 제목·내용·기한을 고치면 검토 완료가 해제됩니다. 공지의 원문 근거를 대조하고 학생에게 공지해도 됩니다를 체크해야 복사·공유·일정에 포함됩니다.

5. 게시와 보관

공지문 복사는 일반 텍스트, LMS용 서식 복사는 HTML과 텍스트를 함께 복사합니다. LMS의 편집기 지원에 따라 모양이 달라질 수 있습니다. 공유하기는 기기의 공유 메뉴를 이용하고 미지원 시 복사로 대신합니다. LearningX 계정 연결·자동 게시 기능은 없으므로 교수자가 직접 붙여넣고 게시합니다.

확정된 날짜의 검토 공지만 종일 ICS로 저장하며 시간·알림은 캘린더에서 별도로 지정하세요. 정리 파일은 Markdown, 전사문·공지는 TXT로 내려받습니다. 이 기기에 저장은 전사문과 정리 결과를 같은 브라우저에 보관하며 녹음 원본은 포함하지 않습니다. 저장하지 않은 작업은 탭을 닫으면 없어집니다. 새 강의는 현재 작업을 비우고 저장 목록은 유지합니다.

강의 정리를 PDF로 저장하려면

정리 결과를 만든 뒤 작업실의 PDF 저장을 누르세요. 브라우저 인쇄 창에서 대상 또는 프린터를 ‘PDF로 저장’으로 선택하고 저장합니다. 모바일에서는 기기의 인쇄·공유 메뉴에서 PDF 저장을 선택합니다. 기기와 브라우저에 따라 메뉴 이름이나 지원 여부가 다릅니다.

현재 수정된 전체 정리·공지·진도·원문 근거·확인 사항을 흰색 문서로 출력합니다. 확인 필요 공지도 검토 상태와 함께 포함되는 교수자 보관용 문서이므로 학생에게 공유하기 전에 확인하세요. 긴 내용은 여러 페이지로 나뉩니다. 인쇄 설정의 머리글·바닥글을 끄면 사이트 주소와 인쇄 날짜를 숨길 수 있습니다. PDF는 기기에 저장되며 외부 PDF 변환 서버로 전송하지 않습니다. Markdown 파일 저장도 계속 사용할 수 있습니다.

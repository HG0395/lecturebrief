데이터 사용 안내

어떤 정보가 어디로 전달되나요?

녹음 전사, Google Gemini 강의 정리, 기기 저장, 호스팅·문의의 데이터 처리를 설명합니다.

녹음과 전사

선택한 녹음은 브라우저 메모리에서 Whisper 모델로 전사합니다. 녹음 원본은 서버나 Google로 업로드하지 않으며 저장한 강의 기록에도 포함하지 않습니다. jsDelivr에서 전사 라이브러리를, Hugging Face 및 연결된 CDN에서 모델을 내려받아 요청 정보·IP 주소가 해당 서비스에 전달될 수 있습니다. 모델은 브라우저 캐시에 남을 수 있습니다.

Gemini 전송 시점과 내용

Google 전송 동의를 체크하고 강의 정리 시작을 누르면 전사문 전체, 과목·강의 날짜·주차, 입력한 강의계획서·이전 진도가 Cloudflare Pages Functions를 거쳐 Google Gemini API에 전달됩니다. 단순 파일 선택으로는 전송하지 않습니다. Google의 API 약관과 해당 프로젝트의 서비스·결제 설정에 따라 처리되므로 민감한 학생 정보는 보내기 전에 지우세요. Gemini API 추가 약관과 Google 개인정보처리방침을 확인하세요.

Cloudflare 서버는 요청과 결과를 중계합니다. 앱이 전사문·정리 결과를 서버 데이터베이스나 로그에 보관하도록 구현하지 않았습니다. 호스팅 사업자의 운영·보안 처리는 별도 정책을 따릅니다. Google API 키는 서버 비밀 설정에만 보관하며 브라우저에 전달하지 않습니다. 이용 코드 인증은 사용하지 않으므로 사이트 방문자가 정리 요청을 보낼 수 있습니다. 자동 재시도하지 않으며 요청에 따라 API 사용량·요금이 발생할 수 있습니다.

기기 보관과 삭제

이 기기에 저장을 누른 경우에만 수업 정보·전사문·강의계획서·정리 결과·공지 검토 상태를 localStorage에 보관합니다. 암호화되지 않으며 자동 저장·계정 동기화는 없습니다. 개별 삭제 버튼이나 브라우저의 사이트 데이터 삭제로 지울 수 있습니다. 모델 캐시는 별도 브라우저 캐시 설정에서 삭제하세요.

새 강의는 현재 작업을 비우지만 저장 목록을 지우지 않습니다. 공용 기기에서는 저장을 피하고 클립보드·다운로드 파일도 직접 정리하세요. 내보내기·복사·공유는 사용자가 선택한 정보를 해당 기기·공유 대상으로 전달합니다. 학교 계정 연결·자동 게시 기능은 없습니다.

광고와 외부 서비스

광고 실행 코드·광고 확인 태그·방문자 분석 스크립트를 사용하지 않습니다. Cloudflare는 페이지·요청 제공과 보안에 접속 정보를 처리할 수 있습니다. Google Fonts 글꼴 다운로드에는 IP 주소와 요청 정보가 전달될 수 있습니다.

데이터 사용 안내

무엇이 기기에 남고, 어디로 전달되나요?

이 안내는 LectureBrief의 전사, Claude 전달, 기기 저장, 광고, 호스팅과 공개 문의에서 처리되는 정보를 설명합니다. “API 없음”은 외부 통신이 전혀 없다는 뜻이 아닙니다.

녹음 파일과 전사문

선택한 오디오는 브라우저 메모리에 읽어 들여 음성 인식 모델로 처리합니다. 사이트 자체는 녹음·전사문·정리 결과를 호스팅 서버나 추론 API로 업로드하는 기능을 구현하지 않았습니다. 파일 선택은 공개 업로드가 아닙니다. 오디오 원본은 저장한 강의 기록에도 포함하지 않습니다.

전사하기를 누르면 jsDelivr에서 Transformers.js 라이브러리를, Hugging Face 및 연결된 파일 CDN에서 모델을 내려받습니다. 이때 IP 주소, 브라우저 정보와 파일 요청 정보가 해당 서비스에 전달될 수 있습니다. 모델은 브라우저 캐시에 남을 수 있습니다. 전사 속도·캐시 유지·모델 파일 크기는 환경에 따라 달라집니다.

Claude에 전달하는 시점

정리 요청문 복사는 전사문·과목·강의 날짜·주차·선택 입력한 강의계획서를 클립보드에 기록합니다. Claude를 여는 것만으로 이 내용이 전달되지는 않습니다. 사용자가 Claude에 붙여넣어 전송하면 Anthropic 서비스의 정책과 계정 설정에 따라 처리됩니다. 민감한 학생 정보는 보내기 전에 삭제하세요. 이 사이트는 Claude 인증 정보나 대화에 접근하지 않습니다.

기기 저장과 삭제

이 기기에 저장을 누르면 과목 정보, 전사문, 강의계획서, 정리 결과, 공지 검토 상태가 이 브라우저의 localStorage에 저장됩니다. 자동 저장이나 계정 동기화는 제공하지 않습니다. 저장한 강의의 삭제 버튼으로 개별 기록을 없앨 수 있습니다. 브라우저의 사이트 데이터 삭제는 저장 기록과 광고 선택도 지웁니다. 캐시된 모델은 브라우저 캐시 설정에서 별도로 지울 수 있습니다.

새 강의는 현재 작업을 비우지만 저장한 강의 목록을 삭제하지 않습니다. 공용 기기에서는 저장을 피하고 사용 후 클립보드와 내려받은 파일도 직접 정리하세요. TXT·Markdown·ICS 다운로드와 공유하기는 사용자가 실행한 내용만 기기의 파일·클립보드·선택한 공유 대상에 전달합니다.

Google AdSense와 광고 선택

게시자 ID는 ca-pub-2685311477810917입니다. 모든 정상 페이지에 확인 메타 태그와 광고 선택 기능이 있습니다. 광고 허용을 선택할 때 제공받은 Google AdSense 스크립트를 불러옵니다. 거절해도 모든 도구를 사용할 수 있습니다. 최초 방문에는 광고 스크립트를 실행하지 않습니다. 하단의 광고 설정에서 선택을 바꿀 수 있으며, 거절 후에는 페이지를 새로고침해 이미 실행한 스크립트를 종료해야 합니다.

Google 및 광고 파트너는 쿠키·기기 식별자·IP 주소·접속 정보 등을 광고 제공, 개인화, 빈도 제어, 보안과 측정을 위해 처리할 수 있습니다. 외부 광고 코드는 페이지에서 실행되는 제3자 코드입니다. 광고 선택은 lecturebrief-ad-choice라는 localStorage 키로 기기에 남습니다. 이 선택 기능은 Google 인증 동의 관리 플랫폼(CMP)을 대체하지 않습니다. 지역별 광고 운영에 필요한 인증 CMP와 계정 설정은 게시자가 별도로 관리해야 합니다.

사이트는 광고 클릭을 요청하거나 보상하지 않으며, 광고 승인·게재·수익을 보장하지 않습니다. 빈 오류 페이지에는 광고 코드를 넣지 않습니다. 작업실의 입력과 공지 검토를 방해하는 수동 광고 슬롯은 만들지 않았습니다.

페이지 제공과 외부 링크

Cloudflare는 페이지 제공과 보안을 위해 IP 주소·요청 시각·접속 정보를 처리할 수 있습니다. Google Fonts에서 글꼴을 불러오며 IP 주소와 브라우저 요청 정보가 전달될 수 있습니다. 사이트 자체의 방문자 분석 스크립트나 사용자 계정 데이터베이스는 없습니다.

GitHub 문의를 이용하면 GitHub 계정과 공개 제보 내용이 해당 서비스에서 처리됩니다. 응답 과정에서 비밀번호나 API 키를 요청하지 않습니다. Cloudflare 개인정보처리방침 · GitHub 개인정보처리방침

작업실가이드FAQ소개·문의

자주 묻는 질문

실제 기능과 제한

무료인가요? 제 API를 사용하나요?

강의 정리는 운영자가 Google AI Studio에서 발급받아 서버에 설정한 Gemini API를 사용합니다. Google 계정의 무료 한도·요금제·할당량을 따르므로 무료라고 보장하지 않습니다. 일반 사용자는 API 키나 이용 코드를 입력하지 않습니다. 사이트 방문자가 정리 기능을 사용할 수 있어 운영자가 API 사용량·한도를 관리해야 합니다. 전사 모델 다운로드에는 인터넷 데이터 비용이 별도로 발생할 수 있습니다.

Gemini 비밀 설정 대기가 표시됩니다.

Cloudflare에 운영자의 API 키가 설정되지 않은 상태입니다. 운영자가 서버 설정을 완료하고 재배포해야 합니다. 화면에 API 키를 붙여넣어 해결하지 마세요. 예시 보기와 전사문 편집·직접 JSON 가져오기는 사용할 수 있습니다.

Google AI Studio 사이트를 따로 열어야 하나요?

아닙니다. 설정이 완료되면 작업실의 강의 정리 시작 버튼으로 서버가 Gemini API를 호출합니다. 결과를 다른 챗봇에서 복사해 돌아오는 단계는 필요하지 않습니다.

녹음 파일이 Google로 올라가나요?

녹음은 브라우저에서 전사합니다. Google 전송에 동의하고 정리 버튼을 누르면 전사문과 수업 정보만 서버를 거쳐 전달됩니다. 전사문에도 개인정보가 담길 수 있으므로 보내기 전에 삭제하세요.

한도 초과·정리 실패가 나옵니다.

운영자의 키 권한, 모델 설정, 사용량·결제 한도 또는 서비스 오류를 확인해야 합니다. 긴 전사문은 수업 단위로 나누어 시도하세요. 사이트는 자동 재시도하지 않습니다. 통신 실패해도 Google에서 이미 처리했을 수 있으므로 사용량을 확인하세요. 기존 작업은 유지됩니다.

전사가 오래 걸리거나 반복 구절이 나옵니다.

첫 실행은 라이브러리·모델 다운로드가 필요합니다. 긴 파일을 나누고 실제 녹음 언어를 선택하세요. Tiny·Base 모델이나 직접 입력을 사용할 수 있습니다. 전문용어·숫자와 반복 구절은 원음으로 확인하세요.

공지와 시험 범위가 정확한가요?

AI 결과의 정확성을 보증하지 않습니다. 새 공지는 미검토 상태이며 원문 대조와 교수자의 확인이 필요합니다. 확인한 공지만 공유할 수 있습니다.

새로고침하거나 기기를 바꾸면 어떻게 되나요?

저장하지 않은 작업은 남기지 않습니다. 명시적으로 저장한 강의만 같은 브라우저에 남으며 기기 간 동기화는 없습니다. 브라우저 데이터 삭제나 저장 제한으로 사라질 수 있으므로 파일로도 보관하세요. Markdown 재가져오기는 지원하지 않으며 JSON 결과는 직접 가져올 수 있습니다.

학교에 자동으로 공지가 올라가나요?

자동 게시와 학교 계정 연결은 없습니다. 공지 복사·LMS용 서식 복사·파일 저장·기기 공유 메뉴를 이용해 교수자가 직접 게시합니다.

광고가 있나요?

광고 실행 코드와 광고 계정 태그는 사용하지 않습니다.

강의 정리를 PDF로 저장하려면

정리 결과를 만든 뒤 작업실의 PDF 저장을 누르세요. 브라우저 인쇄 창에서 대상 또는 프린터를 ‘PDF로 저장’으로 선택하고 저장합니다. 모바일에서는 기기의 인쇄·공유 메뉴에서 PDF 저장을 선택합니다. 기기와 브라우저에 따라 메뉴 이름이나 지원 여부가 다릅니다.

현재 수정된 전체 정리·공지·진도·원문 근거·확인 사항을 흰색 문서로 출력합니다. 확인 필요 공지도 검토 상태와 함께 포함되는 교수자 보관용 문서이므로 학생에게 공유하기 전에 확인하세요. 긴 내용은 여러 페이지로 나뉩니다. 인쇄 설정의 머리글·바닥글을 끄면 사이트 주소와 인쇄 날짜를 숨길 수 있습니다. PDF는 기기에 저장되며 외부 PDF 변환 서버로 전송하지 않습니다. Markdown 파일 저장도 계속 사용할 수 있습니다.

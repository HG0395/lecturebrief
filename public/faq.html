자주 묻는 질문

작업 중 궁금한 점

사용자의 API나 API 비용이 발생하나요?

이 사이트는 OpenAI·Anthropic 등 유료 추론 API를 호출하지 않으며 API 키를 받지 않습니다. 전사는 브라우저에서 실행하고 정리는 교수님의 Claude 웹·앱에서 직접 수행합니다. Claude 구독 비용과 사용량 제한, 인터넷 데이터 비용은 별개입니다.

녹음만 넣으면 전체 요약까지 자동으로 되나요?

아닙니다. 녹음 전사하기로 전사문을 만든 뒤, 정리 요청문을 Claude에 붙여넣고 결과 JSON을 가져와야 합니다. 이 사이트는 강의 전체를 자체적으로 이해해 요약하는 모델을 실행하지 않습니다.

Claude에 음성 파일을 바로 올리면 안 되나요?

이 도구는 호환성이 높은 텍스트 전달을 기준으로 만들었습니다. 전사문과 수업 정보를 요청문으로 복사하므로 Claude의 음성 업로드 지원 여부에 의존하지 않습니다.

전사가 너무 오래 걸리거나 실패해요.

첫 실행은 모델 파일을 내려받아 시간이 더 걸립니다. 네트워크가 jsDelivr 또는 Hugging Face를 차단하는지 확인하세요. 긴 파일을 나누고 Tiny 모델을 선택해 보세요. 메모리가 부족하거나 브라우저가 코덱을 지원하지 않을 수 있습니다. WAV·MP3로 다시 준비하거나 이미 만든 전사문을 직접 입력할 수 있습니다. 처리가 끝날 때까지 탭을 열어 두세요.

JSON 형식이 잘못됐다는 안내가 나와요.

Claude 답변에서 첫 중괄호부터 마지막 중괄호까지 전체를 복사하세요. summary, sections, notices, progress가 포함되어야 합니다. JSON 앞뒤에 일반 설명이 붙어 있으면 제거하세요. JSON 코드블록 자체는 가져올 수 있지만 문법 오류나 중간 생략 기호는 허용되지 않습니다.

과제나 시험을 잘못 공지할까 걱정돼요.

새 공지는 모두 미검토 상태이며 검토 완료 전에는 공유 대상에 포함되지 않습니다. 날짜와 제출 방법을 원문과 대조하세요. 타임스탬프는 확인을 돕는 근거이며 내용이 정확하다는 보장은 아닙니다. 원문에 없는 날짜는 비워 두고 교수님께 확인하는 방식입니다.

새로고침하면 내용이 사라지나요?

저장 버튼을 누르지 않은 작업은 새로고침이나 탭 닫기로 없어집니다. 이 기기에 저장한 강의는 같은 브라우저의 localStorage에 남습니다. 브라우저 데이터 삭제, 시크릿 모드 종료, 저장 공간 제한으로 없어질 수 있으니 중요한 기록은 정리 파일로 내려받으세요. 오디오 원본은 저장 기록에 포함되지 않습니다.

카카오톡이나 학교 LMS에 자동으로 올라가나요?

아닙니다. 공지문 복사, 서식 복사, 텍스트 다운로드, 기기의 공유 메뉴를 제공합니다. 교수님이 게시할 채널에 직접 붙여넣고 최종 내용을 확인한 뒤 게시합니다. 학교 계정이나 카카오톡 비밀번호를 입력하는 기능은 없습니다.

브라우저를 바꾸거나 휴대전화에서 이어 할 수 있나요?

기기 간 동기화는 지원하지 않습니다. 정리 파일을 내려받아 문서로 확인할 수 있지만 Markdown 파일을 작업실에 다시 가져오는 기능은 없습니다. Claude의 원본 JSON을 보관했다면 다른 기기에서 다시 결과 가져오기를 사용할 수 있습니다.

광고가 표시되나요?

이 사이트는 광고 스크립트를 사용하지 않으며 광고를 표시하지 않습니다. 전사 모델 다운로드와 외부 서비스 이용에 관한 사항은 데이터 사용 안내를 확인하세요.

사이트 소개·문의

강의 다음의 일을 줄입니다

LectureBrief는 교수자가 녹음·수업 기록을 강의 전체 정리, 학생에게 전달할 공지, 실제 수업 진도로 바꾸고 검토하는 작업실입니다. 녹음 전사는 브라우저에서, 강의 정리는 Google Gemini API로 처리합니다.

세 가지 결과

  • 강의 전체 정리: 개념·설명·사례·질의응답을 주제별로 검토합니다.
  • 공지: 과제·시험·준비 사항과 원문 근거를 대조한 뒤 공유합니다.
  • 진도: 실제 완료 범위, 다음 예고, 준비 사항을 구분합니다.

역할과 한계

Google·Gemini·LearningX의 공식 또는 제휴 제품이 아닙니다. 전사와 AI 정리의 정확성, 공지 기한의 완전성을 보증하지 않습니다. 교수자가 원문을 확인하고 최종 게시해야 합니다. 학교 로그인이나 자동 공지 게시 기능은 없습니다. 녹음 권한이 있는 자료만 사용하고 개인정보를 제외하세요.

문의·오류 제보

GitHub에 문의하기 ↗는 공개 제보이며 GitHub 계정이 필요합니다. 브라우저·실행 버튼·기대 결과·실제 결과를 적어 주세요. 원본 강의, 학생 개인정보, API 키나 비밀번호는 첨부하지 마세요. 비공개 이메일 창구나 응답 기한을 제공하지 않습니다.

공개 코드

GitHub 저장소 ↗에서 변경 내역을 볼 수 있습니다. Cloudflare Pages와 Pages Functions로 배포합니다. 외부 서비스 처리와 보관 방식은 데이터 사용 안내를 참고하세요.
